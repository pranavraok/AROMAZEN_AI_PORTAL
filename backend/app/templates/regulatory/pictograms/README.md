# GHS pictograms

Public-domain OSHA artwork downloaded from https://www.osha.gov/hazcom/pictograms.
These files are embedded in generated DOCX files, with no network dependency.

OSHA inline-images mapping: GHS01=image3.png, GHS02=image2.png,
GHS03=image1.png, GHS04=image6.png, GHS05=image5.png, GHS06=image4.png,
GHS07=image9.png, GHS08=image7.png, GHS09=image8.png.

The artwork is not a classification decision. Selection uses the saved mixture
label elements, not every hazard assigned to an individual ingredient.
